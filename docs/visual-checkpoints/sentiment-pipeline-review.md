# SentimentPipeline visual checkpoint

SentimentPipeline was hardened from a fabricated live NLP dashboard with average sentiment, message volumes, active sources, alerts, source-specific claims, influencer activity, coordinated-campaign detection, Kafka throughput, scan timestamps, and a live NLP/webhook architecture. Its local Scan Now timer had no ingestion or model backend. Those claims and actions were removed.

The page documents source authorization and terms, timestamps, deduplication, language coverage, freshness, provenance, model/version and labeling, confidence/calibration, bias and language limits, drift, human review, message counts/denominators, trend windows, alert routing/suppression/delivery, incident ownership, content minimization, consent, retention/deletion, sensitive attributes, least privilege, and auditability. Files: `sentiment-pipeline-desktop.webp`, `sentiment-pipeline-mobile.png`.
