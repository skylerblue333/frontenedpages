# SocialEvents visual checkpoint

SocialEvents was hardened from a marketing screen claiming live social events and displaying fabricated active-user, transaction, success-rate, and response-time metrics. Those claims and controls were removed.

The page now documents the unavailable state for event and organizer provenance, venue and timezone, accessibility, capacity, age/safety rules, moderation, RSVP ownership/idempotency, waitlists/cancellations, attendance, location/livestream security, communication consent, reminders, payments/refunds, privacy, retention/deletion, emergency contacts, and human review. Files: `social-events-desktop.webp`, `social-events-mobile.png`.
