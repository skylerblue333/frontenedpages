# SkillBadges visual checkpoint

SkillBadges was hardened from a generic authenticated CRUD shell with unsupported Sign In, New, Search, Settings, loading, and empty-data behavior. No badge definition, criterion, learner, course, assessment, completion, score, certificate, ranking, reward, wallet, privacy, or authorization backend was established. Those controls and claims were removed.

The page documents versioned criteria and issuer provenance, evidence requirements, expiry/revocation, learner ownership, course/assessment records, score provenance, human review/appeals, consented public display, ranking denominators/anti-gaming, certificate verification, wallet custody, ledger-backed rewards, privacy, retention/deletion, auditability, and honest operational states. Files: `skill-badges-desktop.webp`, `skill-badges-mobile.png`.
