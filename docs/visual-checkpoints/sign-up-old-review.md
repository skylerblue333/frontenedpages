# SignUp_old visual checkpoint

SignUp_old was hardened from an unsafe legacy flow using `@ts-nocheck`, a generic AI feature-router placeholder, local code generation, an unsupported Implement action, simulated signup and dashboard redirect, and unverified email/password/name/referral collection. Those operations and claims were removed.

The page documents server-side registration, credential and referral provenance, email ownership, abuse controls, consent, model/prompt governance, code provenance/licensing, sandboxing, human review, deployment controls, wallet custody, ledger-backed benefits, audit logs, and honest states. Files: `sign-up-old-desktop.webp`, `sign-up-old-mobile.png`.
