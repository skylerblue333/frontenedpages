# CitizenPassport visual checkpoint

CitizenPassport was upgraded from a generated Anonymous Citizen passport with a passport number, VERIFIED badge, trust score, reputation dimensions, governance rights, staking rewards, and citizenship progression to an explicit unavailable credential-and-reputation boundary. It does not display or infer identity, citizenship, verification, scores, governance access, wallet ownership, staking, payouts, or rewards.

Files: `citizen-passport-desktop.webp`, `citizen-passport-mobile.png`.
