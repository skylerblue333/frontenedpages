No health check, maintenance lookup, retry, sign-in, API request, database read or write, transaction lookup, payment check, wallet check, deletion check, upload check, incident lookup, log access, recovery action, redirect, content mutation, or sensitive-action retry is performed.

Files: `error503-desktop.webp`, `error503-mobile.png`.

The 390px capture was reviewed for readable service-unavailable disclosure, safe home/back/contact navigation, uptime/dependency boundary, infrastructure and sensitive-action warn-and-proceed notice, and absence of horizontal overflow.
