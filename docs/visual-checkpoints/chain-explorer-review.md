# ChainExplorer visual checkpoint

The Chain Explorer screen renders an explicit unavailable blockchain-exploration boundary. It does not display or claim chain IDs, networks, nodes, indexed blocks, addresses, tokens, balances, transactions, fees, confirmations, finality, freshness, reorganization state, or independent verification.

Files: `chain-explorer-desktop.webp`, `chain-explorer-mobile.png`.

The reviewed mobile capture keeps the unavailable blockchain disclosure and explorer-readiness content readable, with the layout stacking vertically without horizontal overflow.
