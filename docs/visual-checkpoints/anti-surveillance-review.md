# AntiSurveillance visual checkpoint

AntiSurveillance was upgraded from fabricated browser-protection activity. The previous screen claimed an active surveillance blocker with 247 tracking attempts blocked, detections for behavioral profiling, cross-site tracking, device fingerprinting, location inference, social graph mapping, and keystroke dynamics, plus DNS, WebRTC, IPv6, HTTP-header, canvas, battery, geolocation, and clipboard results. It also exposed Block, Run Scan, Update Blocklists, Disable, and Clear Session controls, six blocklist counters, 83 beacons, 12 fingerprint attempts, and 1.2 MB of data saved. No browser extension, network filter, telemetry source, blocklist provider, scan implementation, session store, or security contract was connected. Those claims and controls were removed.

Files: `anti-surveillance-desktop.webp`, `anti-surveillance-mobile.png`.

The 390px capture was reviewed for readable wrapped privacy-control disclosure, stacked telemetry/check/blocklist/session boundary cards, visible privacy/security/monitoring links, sensitive-data warning, and absence of horizontal overflow.
