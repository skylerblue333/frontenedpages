# CertificateManager visual checkpoint

The Certificate Manager screen renders an explicit unavailable credential boundary. It does not create or display certificates, badges, learner records, issuer signatures, verification results, expiration, revocation, accreditation, blockchain mints, token IDs, wallet ownership, networks, transaction hashes, or on-chain settlement.

Files: `certificate-manager-desktop.webp`, `certificate-manager-mobile.png`.

The reviewed mobile capture keeps the unavailable credential disclosure and readiness content readable, with the layout stacking vertically without horizontal overflow.
