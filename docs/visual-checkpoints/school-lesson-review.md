# SchoolLesson visual checkpoint

SchoolLesson was already hardened from a hard-coded course outline with completed lessons and progress, simulated video playback, XP rewards, saved notes, downloadable resources, discussions, likes, comments, and completion actions. Those claims and mutations were removed because no verified lesson, learner, media, storage, community, grading, or reward contracts were established.

The page documents verified course/learner ownership, authorized content delivery, licensing, media availability, progress events, assessment rules, notes and file storage, moderation, privacy, retention, accessibility, and explicit playback/save/completion/error/retry requirements. Files: `school-lesson-desktop.webp`, `school-lesson-mobile.png`.
