It was replaced with this explicit tutorial-readiness boundary. No tutorial, lesson, progress, completion, certificate, learner record, or availability state is displayed, entered, stored, calculated, issued, or mutated from this page. The registered route is `/onboarding-tutorial`.

No auth check, tutorial or lesson lookup, media load, step navigation, progress update, completion, assessment, certificate issuance, API request, database read or write, export, or deletion is read, calculated, displayed, asserted, initiated, or simulated.

Files: `onboarding-tutorial-desktop.webp`, `onboarding-tutorial-mobile.png`.

The 390px capture was reviewed for readable wrapped unavailable disclosure, stacked tutorial-readiness cards, stacked learner/provenance/progress/education-privacy surfaces, education-records/personal-data/privacy/safety/accessibility/security/safeguarding/authorization warn-and-proceed notice, safe onboarding/learning/security/privacy links, and absence of horizontal overflow or fake lessons, progress, completion, certificates, educational credit, learner records, or privacy claims.
