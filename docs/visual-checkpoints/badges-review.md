# Badges visual checkpoint

Badges was upgraded from fabricated platform metrics and generic feature claims. The previous screen claimed live data, advanced analytics, seamless automation, 802K+ active users, 2.4M transactions, 99.9% success, and 45ms response time, with a Get Started action. No achievement catalog, learner identity source, criteria evaluator, evidence store, issuer authority, credential format, revocation registry, privacy model, or audit contract was connected. Those claims and actions were removed rather than implying that a person earned, holds, or can verify a badge.

Files: `badges-desktop.webp`, `badges-mobile.png`.

The 390px capture was reviewed for readable wrapped achievement disclosure, stacked issuer/learner/award/records cards, visible certification/progress/privacy links, sensitive-data warning, and absence of horizontal overflow.
