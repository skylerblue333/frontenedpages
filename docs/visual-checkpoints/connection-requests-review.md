# ConnectionRequests visual checkpoint

ConnectionRequests was upgraded from a fake sign-in gate, New, search, settings, loading, and empty-list controls without an authenticated identity, recipient directory, request service, privacy policy, notification path, moderation controls, or persistence. Those controls were removed rather than implying that a social relationship can be created or changed. No person, profile, username, relationship, request, acceptance, rejection, cancellation, search result, member count, notification, message, block, report, or moderation state is read, stored, displayed, or simulated.

Files: `connection-requests-desktop.webp`, `connection-requests-mobile.png`.

The 390px capture was reviewed for readable wrapped connection-requests-unavailable disclosure, stacked identity/recipient, request transition, notification/privacy, and audit/authorization readiness cards, explicit credential warning, and absence of horizontal overflow.
