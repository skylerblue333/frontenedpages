# BlockUser visual checkpoint

BlockUser was upgraded from a generic block-user placeholder with a fake Activate/Deactivate control. No authenticated user lookup, block-list service, policy or report evidence, moderator or account-owner authorization, scope and duration semantics, reversible state, notice, appeal workflow, privacy model, or audit contract was connected. The control was removed rather than implying that a person was blocked, unblocked, notified, or reviewed.

Files: `block-user-desktop.webp`, `block-user-mobile.png`.

The 390px capture was reviewed for readable wrapped blocking disclosure, stacked identity/policy/notice/permission cards, visible blocked-user/moderation/audit links, sensitive-data warning, and absence of horizontal overflow.
