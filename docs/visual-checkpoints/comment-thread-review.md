# CommentThread visual checkpoint

CommentThread was upgraded from a sign-in gate, New action, search, settings, loading state, and empty-item prompt without a connected thread source, identity contract, reply relationship, moderation policy, authorization check, or audit record. Those controls were removed rather than implying that a comment, author, reply, reaction, notification, or moderated outcome exists. No comment, author, avatar, timestamp, parent-child relation, reply, reaction, mention, notification, moderation decision, report, or engagement count is read, calculated, displayed, stored, or simulated.

Files: `comment-thread-desktop.webp`, `comment-thread-mobile.png`.

The 390px capture was reviewed for readable wrapped comment-thread-unavailable disclosure, stacked thread/search/moderation/authorization readiness cards, clear current-boundary warnings, and absence of horizontal overflow.
