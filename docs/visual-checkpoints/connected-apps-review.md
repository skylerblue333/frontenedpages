# ConnectedApps visual checkpoint

ConnectedApps was upgraded from a generic connected-app placeholder with an Activate/Deactivate toggle and no provider, account, OAuth scope, token, sync behavior, privacy notice, audit event, or revoke operation. It has been removed rather than implying that an external app is connected or that access can be changed. No provider, external account, app identity, OAuth grant, permission, scope, access token, refresh token, connection date, sync record, imported data, webhook, or connected-app status is read, stored, displayed, or simulated.

Files: `connected-apps-desktop.webp`, `connected-apps-mobile.png`.

The 390px capture was reviewed for readable wrapped connected-apps-unavailable disclosure, stacked provider/ownership, OAuth/token, sync/webhook, and audit/privacy/secret-handling readiness cards, explicit credential warning, and absence of horizontal overflow.
