# Farming visual checkpoint

Farming was upgraded from a screen that hard-coded farming pools, APY, TVL, multipliers, rewards, token projects, raised amounts, participants, allocation tiers, audited-contract and impermanent-loss claims, plus auth-dependent farm and IDO controls. No chain, contract, oracle, wallet, market, issuer, audit, or transaction evidence supported those claims, so metrics and financial actions were removed.

The screen preserves typed informational Yield farming and Launchpad tabs only. No auth check, wallet connection, token query, pool query, market lookup, balance calculation, APY/TVL calculation, staking, farming, launchpad participation, allowance, transaction simulation, signing, API request, database read or write, notification, export, or personal-data operation is performed.

Files: `farming-desktop.webp`, `farming-mobile.png`.

The 390px capture was reviewed for readable wrapped unavailable disclosure, responsive tabs, stacked DeFi/launchpad readiness cards, stacked liquidity/wallet and project/governance surfaces, crypto/finance/tax/legal/privacy/authorization warn-and-proceed notice, safe crypto/pool/wallet/security/availability links, and absence of horizontal overflow.
