# BanSuspendUser visual checkpoint

BanSuspendUser was upgraded from a generic ban/suspend placeholder with a fake Activate/Deactivate control. No authenticated moderator role, target-user lookup, policy taxonomy, evidence record, proportionality review, duration semantics, appeal workflow, notification provider, reversible enforcement service, or audit contract was connected. The control was removed rather than implying that a user was banned, suspended, restored, notified, or reviewed.

Files: `ban-suspend-user-desktop.webp`, `ban-suspend-user-mobile.png`.

The 390px capture was reviewed for readable wrapped enforcement disclosure, stacked identity/policy/appeals/permissions cards, visible moderation/blocked-user/audit links, sensitive-data warning, and absence of horizontal overflow.
