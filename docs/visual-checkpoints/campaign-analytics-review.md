# CampaignAnalytics visual checkpoint

The Campaign Analytics screen renders an explicit unavailable analytics boundary. It does not report campaigns, channels, audiences, consent, impressions, clicks, spend, conversions, revenue, attribution, cohorts, lift, optimization, exports, or audit results.

Files: `campaign-analytics-desktop.webp`, `campaign-analytics-mobile.png`.

The reviewed mobile capture keeps the unavailable analytics disclosure and campaign-readiness content readable, with the layout stacking vertically without horizontal overflow.
