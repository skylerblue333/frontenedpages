# CommentsSection visual checkpoint

CommentsSection was upgraded from generic placeholder copy and an Activate/Deactivate demo control without real comments, author identity, parent context, pagination, moderation policy, authorization, persistence, or success and failure states. The demo mutation was removed rather than implying that a comment section was activated or that any community record exists. No comment, author, avatar, timestamp, parent relation, reply, reaction, mention, notification, report, moderation decision, or engagement count is read, displayed, stored, or simulated.

Files: `comments-section-desktop.webp`, `comments-section-mobile.png`.

The 390px capture was reviewed for readable wrapped comments-section-unavailable disclosure, stacked source/parent, replies/search/pagination, moderation/notification, and privacy/audit readiness cards, clear current-boundary warnings, and absence of horizontal overflow.
