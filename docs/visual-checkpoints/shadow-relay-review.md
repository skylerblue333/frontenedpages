# ShadowRelay visual checkpoint

ShadowRelay was hardened from a fabricated relay-network builder with named nodes, locations, latency, trust/load percentages, anonymity levels, encryption and onion-routing guarantees, Tor comparisons, path construction, random-chain selection, traffic routing, activation, and disconnect behavior. Those claims and controls were removed.

The page documents node operators and endpoint provenance, availability/capacity, routing and transport protocols, encryption/key exchange, exit policy, independently reviewed privacy properties, metadata exposure, threat model, abuse controls, consent, credentials, access scope, retention, incident response, support, disconnect semantics, authorization, and honest connection/failure/retry states. Files: `shadow-relay-desktop.webp`, `shadow-relay-mobile.png`.
