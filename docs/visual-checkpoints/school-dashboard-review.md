# SchoolDashboard visual checkpoint

SchoolDashboard was already hardened from a fabricated learner dashboard displaying course progress, learner totals, XP, certificates, course names, and “Minted on-chain” credentials without verified learner, course, assessment, or blockchain records. Those claims and links were removed rather than presenting a false learning history.

The page documents authenticated learner ownership, course and lesson records, progress persistence, assessment and grade integrity, instructor/content provenance, accessibility, certificate policy, on-chain verification when applicable, privacy, retention, and honest empty/loading/error/retry states. Files: `school-dashboard-desktop.webp`, `school-dashboard-mobile.png`.
