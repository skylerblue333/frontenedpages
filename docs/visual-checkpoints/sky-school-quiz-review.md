# SkySchoolQuiz visual checkpoint

SkySchoolQuiz was preserved as a bounded authored question-and-answer practice interaction. Its score, pass/fail label, answer review, explanations, and retake behavior are calculated only in the browser session. The registered route now supplies a documented default authored lesson instead of rendering an unexplained empty state when no `lessonId` is provided.

Unsupported authentication and learner-identity dependencies were removed. Certificate, download, share, server-grade, XP, badge, token-reward, wallet, transcript, public-achievement, continuation, privacy, and authorization claims were removed or explicitly bounded. Files: `sky-school-quiz-desktop.webp`, `sky-school-quiz-mobile.png`.
