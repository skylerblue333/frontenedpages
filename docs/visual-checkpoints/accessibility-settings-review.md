# AccessibilitySettings visual checkpoint

AccessibilitySettings was upgraded from a generic placeholder and inert Activate/Deactivate toggle to a truthful accessibility-readiness boundary. It now distinguishes browser and operating-system controls from unavailable account preference persistence, assistive-technology testing, remediation workflow, compliance evidence, and saved settings. No preference is saved or applied by this route.

Files: `accessibility-settings-desktop.webp`, `accessibility-settings-mobile.png`.

The 390px capture was reviewed for readable wrapped accessibility disclosure, stacked preference-boundary cards, visible accessibility/issue-reporting/settings links, sensitive-data warning, and absence of horizontal overflow.
