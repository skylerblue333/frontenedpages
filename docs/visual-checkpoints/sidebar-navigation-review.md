# SidebarNavigation visual checkpoint

SidebarNavigation was hardened from a placeholder with a nonfunctional Activate/Deactivate control and no route registry, account context, unread counts, feature availability, permission, accessibility, privacy, or authorization backend. That control was removed.

The page documents authoritative route ownership, destinations and redirects, not-found handling, account/workspace/tenant context, role-aware feature visibility, unread-state source, backend capability/maintenance status, keyboard/focus/mobile behavior, external-link warnings, privacy, security, and authorization. Files: `sidebar-navigation-desktop.webp`, `sidebar-navigation-mobile.png`.
