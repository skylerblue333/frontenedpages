No auth check, customer query, cohort calculation, revenue query, CAC or LTV calculation, churn or retention calculation, forecast, segmentation, search, settings mutation, API request, database read or write, notification, export, deletion, or personal-data operation is read, calculated, displayed, asserted, initiated, or simulated.
