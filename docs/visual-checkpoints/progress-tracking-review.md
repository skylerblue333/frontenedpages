It presented those values as a learner journey and exposed practice controls without verified learner scope, assessment methodology, persistence, privacy, or authorization. No learner or course auth check, language-exchange query, activity aggregation, score or level calculation, streak or milestone mutation, XP or reward issuance, recommendation, API request, database read or write, export, or deletion is read, calculated, displayed, asserted, initiated, or simulated.

Files: `progress-tracking-desktop.webp`, `progress-tracking-mobile.png`.
