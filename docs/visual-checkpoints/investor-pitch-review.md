# InvestorPitch visual checkpoint

It also offered a download action without a controlled document, source register, disclosure review, investor suitability, securities compliance, or authorization boundary. Those claims and action were removed. No fundraising offer, valuation, projection, investor claim, security, or downloadable deck is displayed or generated from this page. The registered route is `/investor-pitch`.
