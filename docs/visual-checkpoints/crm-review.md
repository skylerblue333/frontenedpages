# CRM visual checkpoint

The CRM Hub renders the upgraded unavailable integration boundary. Static contacts, companies, email addresses, deal stages, pipeline values, lead scores, revenue charts, win rates, activity records, and Add Contact actions are not presented as real data. The screen instead states the authorization, ownership, privacy, data-quality, pipeline, analytics, retention, and audit requirements that are not connected.
