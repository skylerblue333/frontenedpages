# SelectDropdownForm visual checkpoint

SelectDropdownForm was hardened from a placeholder with a nonfunctional Activate/Deactivate control and no form, option, validation, submission, persistence, or authorization backend. That control was removed. No option, value, form state, user, tenant, validation result, submission, saved record, notification, privacy, compliance, or availability state is displayed, calculated, stored, transmitted, verified, granted, or mutated.

The page documents option ownership and semantics, labels/values/order/localization/deprecation, requiredness and constraints, server revalidation, idempotent submission, success/error states, authenticated ownership, draft versus committed state, audit history, retention/deletion, authorization, sensitive-value handling, keyboard/screen-reader behavior, focus handling, and abuse controls. Files: `select-dropdown-form-desktop.webp`, `select-dropdown-form-mobile.png`.
