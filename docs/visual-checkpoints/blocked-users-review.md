# BlockedUsers visual checkpoint

BlockedUsers was upgraded from fabricated platform metrics and generic feature claims. The previous screen claimed live data, advanced analytics, seamless automation, 802K+ active users, 2.4M transactions, 99.9% success, and 45ms response time, with generic Get Started, Learn More, and Documentation actions. No blocked-account registry, identity source, policy taxonomy, evidence record, actor authorization, scope or duration semantics, notice, appeal workflow, privacy model, or audit contract was connected. Those claims and actions were removed rather than implying that anyone is blocked, restored, notified, or reviewed.

Files: `blocked-users-desktop.webp`, `blocked-users-mobile.png`.

The 390px capture was reviewed for readable wrapped blocked-user disclosure, stacked identity/policy/notice/permission cards, visible block/moderation/audit links, sensitive-data warning, and absence of horizontal overflow.
