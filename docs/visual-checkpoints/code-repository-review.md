# CodeRepository visual checkpoint

CodeRepository was upgraded from an inert sign-in card plus unconnected search, New, and Settings controls to a truthful authenticated repository boundary. Signed-out users receive a working secure sign-in action. The page explicitly states that repositories, branches, commits, files, pull requests, issues, activity, permissions, security results, and repository mutations are not loaded or performed without a verified provider connection and scope.

Files: `code-repository-desktop.webp`, `code-repository-mobile.png`.

The 390px capture was reviewed for readable authentication messaging, a visible sign-in action, and absence of horizontal overflow.
